# Employee Salary Analysis - Task 3

**Veda Technology Virtual Internship**
**Track:** AI & ML Track | **Level:** Level 1 - Day 3

## 📝 Description
This repository contains a Python program designed to analyse employee salaries and calculate the total, average, highest, and lowest salary. This project was completed as part of Task 3 for the Veda Technology Virtual Internship.

## 🎯 Objective
Practice numerical data processing using Python.

## 🛠️ Tools Used
* Python
* Jupyter Notebook
* Pandas 

## 🧠 Approach & Methodology
To fulfil the project deliverables and hints provided in the task guide, the following steps were taken:
1. **Dataset Creation:** Manually created a dataset of employee salaries by storing the numerical values in a Python list.
2. **Data Processing:** Used built-in Python functions (`sum()`, `max()`, `min()`, and `len()`) for basic calculations to process the data without external dependencies.
3. **Advanced Analysis:** Leveraged the `pandas` library to convert the list into a DataFrame, demonstrating industry-standard methods for extracting descriptive statistics (`.describe()`).
4. **Verification:** Outputted the results and compared the calculated statistical values with the original data to verify the logic.

## 📊 Outcome & Results
The script successfully analyzed the list of 10 employees and generated the following accurate statistics:
* **Total Salary:** $568,000
* **Average Salary:** $56,800.00
* **Highest Salary:** $82,000
* **Lowest Salary:** $38,000
